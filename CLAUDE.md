# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Python type stub library for [LSP](https://github.com/sublimelsp/LSP) (Language Server Protocol client for Sublime Text). Part of the [SublimeLSP](https://github.com/sublimelsp) organization.

The repository provides `.pyi` stub files so that LSP plugin developers get type checking and autocompletion for the LSP package's public API.

## Current State

The project is in its initial phase — no source code, build system, tests, or CI/CD are configured yet. Only LICENSE and README.md exist.
